# prodloop V0.5 企业数据可视化模块验证报告

验证日期：2026-09-03

## 本次目标

把企业图表、分析看板、地图、监控视图和可视化报告纳入 `prodloop` 原有交付状态机，避免指标口径未定义、图型误导、假交互、权限泄漏或只凭截图判定完成。

## 实现范围

- 新增原创的企业数据可视化设计与验收规范。
- 区分精确查询、比较、趋势、分布、关系、构成、流动、地理和层级等数据任务。
- 将指标来源、口径、粒度、分母、单位、时区、刷新、权限和独立复算纳入合同。
- 覆盖坐标轴、比例面积、排序、精度、缺失值、异常值、不确定性、颜色语义和非颜色编码。
- 将 Dashboard 设计为“总览、解释、授权记录与行动”的工作流，而不是 KPI 卡片集合。
- 覆盖筛选、联动、下钻、返回、导出、加载、无结果、陈旧、部分、权限不足和查询失败状态。
- 状态 schema 升级为 V4，新增 `visualization_scope`。
- 初始化创建 `DATA_VIS_CONTRACT.md` 和 `DATA_VIS_VERIFICATION.md`。
- V1/V2/V3 状态可非破坏性启用数据可视化门禁；启用前保留状态与 manifest 备份，不覆盖已有产物。
- G0 拒绝未明确的可视化范围；范围内时，G3 拒绝不完整的数据可视化合同，G6 拒绝不完整的验收报告。

## 来源与许可证边界

V0.5 参考了数据可视化领域的通用事实和方法，但规范文本、状态结构、模板与脚本均为本仓库独立编写。

本版本没有复制 `lieflat-charts` 的 `SKILL.md`、HTML 模板、图表目录、token、脚本或视觉资产。该仓库在核验时使用 PolyForm Noncommercial License 1.0.0；商业项目若要直接使用其受保护内容，需要另行确认并获得适当授权。

第三方图库、模板和设计系统不能自动成为可商用实现资产。实际采用前仍需核对当时的许可证、维护状态、技术栈、品牌和数据安全边界。

## 证据边界

- 自动化门禁能阻止缺少产物或状态错误，不能自动证明指标定义和视觉判断本身正确。
- 图表选择规则不能替代业务负责人对指标口径、权限和决策后果的确认。
- V0.5 尚未经过多个真实企业数据产品的前向测试，不声称能够自动保证所有可视化正确。
- 第一次真实使用应记录指标口径冲突、独立复算差异、误导性编码、交互缺陷和人工干预点，用实际失败继续改进。
